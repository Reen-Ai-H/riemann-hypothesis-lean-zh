# 01 · 黎曼猜想是什么（零基础版）

> 读完这一篇，你应该能回答三个问题：黎曼猜想说的是什么？为什么它这么重要？"广义黎曼猜想"又是什么？

## 1. 从质数说起

质数是只能被 1 和自身整除的数：2、3、5、7、11、13……

质数看起来毫无规律，但"大量地看"时又有规律。1896 年数学家证明了**质数定理**：
不超过 x 的质数大约有 x / ln x 个。比如 x = 100 万时，估计值约 72,382，真实值是 78,498，误差在一成以内。

问题在于：**这个误差到底有多大？** 能不能把它控制得尽量小？

## 2. 黎曼的发现

1859 年，德国数学家黎曼写了一篇只有 8 页的论文。他发现，质数的分布被一个函数完全"编码"了，
这个函数现在叫做**黎曼 ζ（zeta）函数**：

```
ζ(s) = 1 + 1/2^s + 1/3^s + 1/4^s + …
```

这里的 s 可以是复数（形如 a + bi 的数，a 叫实部，b 叫虚部）。

黎曼证明了一件惊人的事：**质数定理的误差有多大，完全由 ζ 函数的"零点"（让 ζ(s) = 0 的那些 s）在哪里决定。**
零点越"整齐"，误差越小。

## 3. 猜想本身

ζ 函数的零点分两类：

| 类型 | 位置 | 说明 |
|---|---|---|
| 平凡零点 | −2, −4, −6, … | 早就清楚，不重要 |
| 非平凡零点 | 都落在实部 0 到 1 之间的"临界带"里 | 这才是关键 |

**黎曼猜想**：所有非平凡零点的实部都恰好等于 1/2。

换句话说，它们全部排在复平面上一条竖直的直线（"临界线" Re s = 1/2）上。

```
   虚部 ↑
        |      ·  ← 非平凡零点
        |      ·
        |      ·       黎曼猜想说：它们全都在
        |      ·       Re s = 1/2 这条线上，
        |      ·       一个都不偏离
  ──────┼──────┼──────┼──→ 实部
        0     1/2     1
        └─ 临界带 ─┘
```

如果黎曼猜想成立，质数定理的误差就被压到了理论上最好的程度，大约是 √x · ln x 这个量级。
用作者在说明里的话来概括：它要的是对"一定大小的质数有多少个"的**最优控制**。

## 4. 为什么这么重要

- **难**：从 1859 年到现在 160 多年，无数顶尖数学家尝试过。计算机已经验证了前十万亿个以上的零点都在线上，但"验证很多个"不等于"证明全部"。
- **悬赏**：它是克雷数学研究所 2000 年公布的七个"千禧年大奖难题"之一，奖金 100 万美元；也是 1900 年希尔伯特 23 个问题中的第 8 个。
- **地基**：数论里有成百上千篇论文以"假设黎曼猜想成立"为前提。它一旦被证明，这些结果会一起变成定理。

## 5. 广义黎曼猜想（GRH）是什么

ζ 函数只是一个大家族里的第一个成员。数学家还定义了**狄利克雷 L 函数** L(s, χ)：

```
L(s, χ) = χ(1)/1^s + χ(2)/2^s + χ(3)/3^s + …
```

这里的 χ（读作"凯"）叫**狄利克雷特征**，可以理解为一种给整数"按余数打标签"的规则，
用来研究"除以 N 余 a 的质数"有多少。比如"个位数是 7 的质数有多少"就是这一类问题。

**广义黎曼猜想**说：所有狄利克雷 L 函数的非平凡零点，实部也都等于 1/2。

ζ 函数就是 χ 取最简单的那个（恒等于 1）时的特例，所以**广义黎曼猜想比黎曼猜想更强**，证明了前者就自动证明了后者。
这次的说明里作者声称证明的正是这个更强的版本。

再往上还有"扩展黎曼猜想"（ERH，针对数域的戴德金 ζ 函数等），作者说预计"再给些时间"也能做到，但这次没有声称已经证明。

## 6. 一个关键的简化：只要证明"右半边没有零点"

ζ 函数和 L 函数都满足一个**函数方程**：s 处的值和 1 − s 处的值紧密相关，零点关于直线 Re s = 1/2 左右对称。

所以，只要证明了"实部大于 1/2 的地方一个零点都没有"，再用对称性，就知道"实部小于 1/2 的地方也没有"，
剩下的零点只能在线上。

这正是本仓库 Lean 代码最后几步做的事，详见 [03-Lean 陈述逐行解读](03-Lean陈述逐行解读.md)。
真正难的、占了 1700 多万行代码的部分，是证明"右半边没有零点"。
